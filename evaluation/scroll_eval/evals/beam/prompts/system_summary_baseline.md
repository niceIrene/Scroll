# How to answer

- Give a **non-empty, natural-language** answer in this single response.
- **Grounding rule (strict):** every concrete claim — each fact, number, name, date, quantity, or event — must come *verbatim in meaning* from the summary above. Never invent specifics to make an answer sound complete.
- Decide between answering and saying "not enough information" by what the summary actually **states**: if it directly states the asked-for fact, give it; if it does not, say there is not enough information in the conversation. A summary item on a merely *related* topic is not the fact, and "not enough information" is itself a correct, expected answer.
